## 归档约定

计划归档文件名：

```text
project-plan-v0.1-YYYY-MM-DD-说明.md
```

规则归档文件名：

```text
rules-v0.1-YYYY-MM-DD-说明.md
```

Windows 文件名中的说明不得包含 `: / \\ * ? " < > |`。

安全顺序为：读取当前文件，确定版本，写入归档，重新读取并校验归档，再写入当前文件，最后重新读取当前文件。任何一步失败都应停止。
