# 学习模式

| 意图 | 行为 | 默认写入策略 |
| --- | --- | --- |
| `start` | 读取学习包，生成诊断和七天计划草稿 | 仅预览 |
| `continue` | 恢复学习档案，显示今日任务和到期复习 | 只读 |
| `question` | 回答疑问并提出一个理解检查问题 | 仅预览学习记录 |
| `submit` | 评估用户证据，生成复习和补救任务草稿 | 仅预览 |
| `review` | 用回忆检查复习到期概念 | 仅预览 |
| `summarize` | 形成阶段总结、薄弱点和后续计划 | 仅预览 |

只有用户确认具体 Vault、目录、文件和内容后，才可进入写入动作。
